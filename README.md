# local_pen

local_pen 让 Claude Code、Codex 或其他支持本地 stdio MCP 的客户端直接修改选中的 `.pen`。浏览器实时预览使用 Pen CLI 无界面渲染，可放在副屏，AI 保存后会自动更新。AI 客户端只需连接 `local_pen`。Pen 桌面模式适合把 Pen 留在当前桌面上直接查看。

## 1. 安装

准备 macOS、Python 3.10+、Node.js 22.19+，以及 Claude Code 或 Codex。把仓库克隆到你打算长期使用的目录。

```bash
git clone https://github.com/wuyongli/local_pen.git
cd local_pen
```

运行与你使用的客户端对应的命令。

```bash
bash setup_local_pen.sh claude
bash setup_local_pen.sh codex
bash setup_local_pen.sh both
```

脚本在包内安装 Pen CLI 0.3.16，注册名为 `local_pen` 的服务。重开 AI 客户端后，Claude Code 可通过 `/mcp` 查看连接，Codex CLI 可用 `codex mcp list` 查看。

```bash
bash setup_local_pen.sh check
```

如果预览页显示渲染不可用，先确认 CLI 版本。需要登录时，在同一个目录运行以下命令并登录自己的 Pen 账号。浏览器预览无需打开 Pen 桌面应用，也无需授予辅助功能权限。 [Pen CLI 安装与认证](https://docs.pencil.dev/for-developers/pen-cli)

```bash
bash setup_local_pen.sh login
```

## 2. 用示例试一次

1. 把 `快速体验.pen` 复制到你的任务目录。在 AI 客户端打开该目录，先说「把 `快速体验.pen` 设为本任务设计稿，把标题改成『今天的待办』」。
2. 本次保存会开启实时预览。手动打开返回的链接一次，再让 AI 修改确认按钮。
3. 把标签页留着。后续只需自然描述设计要求，AI 保存后，原标签页会自动显示新稿。需要自查画面时，AI 可用 `preview_png`。

「预览本任务设计图」会显示整个 `.pen` 画布。所有可见画板按原位置排列，包括随内容调整大小的画板。画板上方显示设计稿里的名称，鼠标停在标题上可看全名。触控板双指捏合和右上角的「+」「−」共用画布缩放比例。放大后，双指滑动或按住拖动可把边角内容移到窗口中央。点「适合窗口」恢复整稿视图。自动刷新会保留当前缩放和查看位置。点击工具栏的百分比可回到 100%。调整窗口或移动到另一块屏幕后，手动设置的实际比例与查看中心保持不变；刷新页面后恢复这个文件的上次视野。「适合窗口」模式会继续适配窗口。

浏览器标签显示「任务名 · local_pen」，同时打开多个任务时可直接区分。名称取自选定设计稿所属的任务目录，自动去掉常见的日期前缀；没有任务信息时使用设计文件名。

点「画板」打开目录，输入画板名称即可筛选，选择结果会在整份画布中定位，不会切换成单画板模式。也可按 `/` 或 `⌘K` 打开搜索，按 `Esc` 关闭；不在输入框内时，按 `1` 恢复 100%。查看位置分别保存在当前标签页及本机浏览器中，不同设计文件各自记忆；浏览器禁用存储时仍可正常查看。

视野记忆适用于新版分块预览。兼容回退到整图模式时，刷新页面会重新适配窗口，不保存该模式的位置，避免覆盖分块预览的记录。

macOS 实时预览复用本地 Pen 渲染进程，保留整稿布局和共享组件，按当前视野加载清晰图块。放大、拖动时自动补图，优先加载可见内容，并缓存视野周边。操作时立即变换已有画面；浏览器逐帧回调延后时，可见页面有 80 毫秒调度兜底。超长画板也不必压缩成一张低清大图。仅缺缓存字体时，会提示字体可能有差异。更新时保留当前视野的一张过渡画面，可见区域新图准备好后整体切换。连续保存时丢弃过期结果；新增画板或改变画布范围后，手动选择的实际缩放和查看位置保持不变。「适合窗口」模式会继续适配整稿。AI 自查用的 `preview_png` 和 PNG 导出方式保持不变。

预览服务独立于 AI 会话。同一任务的会话共用本机预览地址。关掉任一会话后，只要原标签页还在轮询，其他会话保存就会继续更新该页。说「停止实时预览」可主动结束服务。如果浏览器与会话连续 10 分钟都未访问服务，空闲进程会自动退出，下次改稿会恢复预览。较早版本的预览服务会在新版 MCP 下次连接时按原地址升级；端口被无关程序占用时才会分配新地址。

## 3. 选自己的工作方式

| 使用场景 | 做法 |
| --- | --- |
| 主屏留在 Pen | 在 Pen 中打开任务稿，改稿时明确要求「保存后在 Pen 中重开」。macOS 窗口重开需完成下方的一次性设置。 |
| 主屏工作，副屏看画板 | 首次改稿后，把返回的预览页拖到副屏再手动全屏。后续保存会自动更新该页。 |
| 先看方案再决定 | 请求 AI 先做临时预览。确认后再让 AI 应用到任务稿。 |

多个会话可编辑同一任务稿。保存使用文件锁。提示稿件已更新时，先读取最新图层，再决定如何应用改动。如果该稿也在 Pen 中打开，进行后台改稿前先在 Pen 保存并关闭它，以免窗口中的旧版本覆盖新稿。要回到 Pen 窗口工作流，先说「停止实时预览」，再在 Pen 打开最新稿。初次使用建议选择工作副本。多屏可设为扩展显示，并在 macOS「桌面与程序坞 → 调度中心」启用「显示器具有单独的空间」。 [Apple 调度中心设置](https://support.apple.com/zh-cn/guide/mac-help/mchlp1119/mac)

### 使用 Pen 窗口自动重开

在安装包目录运行以下命令，按提示添加辅助程序。安装浏览器预览的人可跳过此步。

```bash
bash setup_local_pen.sh desktop
```

把目标 `.pen` 打开在普通 Pen 窗口。改稿前保存你在窗口里的手改。独立全屏的 Pen 窗口使用浏览器实时预览模式更合适。

## 4. 升级与其他客户端

如果客户端已指向此仓库，在仓库目录运行 `git pull --ff-only`，然后重启客户端。1.22.0 的分块预览需要随包保留 `pen_native_renderer.mjs` 和 `pen_preview.js`。已有独立安装时，可将仓库里的 Python、JavaScript 文件一起更新到现有服务目录，保留已授权的 `pen-reopen`。切换安装位置时，先移除对应客户端的旧注册，再运行安装命令。

```bash
claude mcp remove local_pen -s user
codex mcp remove local_pen
```

升级前已经打开的旧版预览页会继续使用旧显示方式。新版服务就绪后，在原链接手动刷新页面一次即可进入分块模式；后续改稿无需再刷新，也无需 AI 打开浏览器。更新仓库代码本身不会重启已经运行的服务。

其他客户端可添加名为 `local_pen` 的本地 stdio 服务。命令使用 Python 3 的绝对路径，参数是 `-B` 和安装目录中 `local_pen_mcp.py` 的绝对路径。设置 `LOCAL_PEN_NODE` 为 Node 的绝对路径，`LOCAL_PEN_CLI` 为安装目录中 `.runtime/node_modules/.bin/pen` 的绝对路径。

### 预览资源管理

- 分块适配器仅启用于已验证的 Pen CLI 0.3.16，并检查安装包标识、入口结构和 Node 加载钩子。其他版本或平台保留现有整图预览；临时失败会自动重试。整图回退仍有原来的尺寸限制。
- 原生渲染器通过 macOS 网络隔离运行，使用本地资源与字体缓存，不调用官方 MCP。渲染中间文件保存在独立临时目录。
- 同一用户最多同时运行两个新版预览渲染进程。单进程达到约 1280 MiB 后回收；独立监控每 250 毫秒检查一次，超过约 1536 MiB 时终止进程。监控不是操作系统级的瞬时硬限额。
- 连续 120 次加载/渲染请求或 60 秒没有渲染请求后回收。下次需要补图时自动恢复，预览地址不变；浏览器继续显示已加载的图块。
- 服务端图块缓存最多 48 MiB、128 块；浏览器最多保留 64 块，最多四个请求在途。版本或倍率切换时，额外最多保留一张当前视野的过渡画面，像素数不超过 800 万（原始像素约 32 MB）；连续改稿不会叠加多份过渡画面。快速移动到尚未缓存的区域仍需等待补图。素材文件更新会使对应版本缓存失效。

## 5. 开发验证

在仓库根目录运行以下命令。测试使用临时文件和模拟渲染器，无需连接 AI 客户端或登录 Pen。

```bash
python3 -B -m unittest discover -s tests -p 'test_*.py'
node --test tests/test_pen_*.cjs
bash -n setup_local_pen.sh
```

原生渲染验收可设置 `LOCAL_PEN_NATIVE_FIXTURE` 为测试稿路径，再运行 `python3 -B -m unittest discover -s tests -p test_pen_native_integration.py -v`。测试始终复制夹具，不修改指定文件；需要正确设置 `LOCAL_PEN_NODE` 和 `LOCAL_PEN_CLI`。

已安装 playwright-core 和无界面 Chromium 时，可设置 `LOCAL_PEN_PLAYWRIGHT` 为模块路径、`LOCAL_PEN_BROWSER` 为浏览器程序路径，运行 `node tests/verify_pen_tiles.cjs /path/to/design.pen`。它在隔离任务与状态目录创建副本，验证画面像素、缩放与画布范围变化、跨 AI 会话保存及固定链接；结束时仅停止测试服务。

预览交互的离线浏览器验收：在同样的 Playwright/浏览器环境变量下运行 `node --test tests/verify_pen_viewer.cjs`。它不读取实际设计稿，也不访问现用预览，覆盖连续操作、无闪白切换、窗口变化和刷新恢复、跨文档记忆、搜索、存储不可用、旧模式定位，以及不同显示比例下的不透明和半透明分块拼接。可见分块先合成到视野画面，避免缩放接缝；实时画面最多 1600 万像素，切换快照最多 800 万像素，缓存仍限制为 64 块。
